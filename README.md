## 📖 About

**CryptoX** is a modern cryptocurrency tracking platform that provides **real-time market data** for thousands of cryptocurrencies. Built with performance and simplicity in mind, CryptoX helps users stay updated with live prices, market trends, and key statistics through a clean and responsive interface.

This project is actively under development and will continue to evolve into a complete cryptocurrency portfolio and analytics platform.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/cryptox.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
